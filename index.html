Heróis de Pixel

Jogo de plataforma 2D em pixel art feito do zero com vibe coding no Claude Code. A primeira versão jogável ficou pronta em 2 horas. Roda no navegador do PC e do celular, sem instalar nada.

Engenharia de dados · projeto acadêmico · 2026

Pipeline de Dados Orquestrado por DAG

Pipeline para um painel diário de vendas: os dados saem de arquivos CSV, passam por limpeza, validação e modelagem e terminam como indicadores publicados.

  • Orquestrador em Python que lê 20 transformações SQL, monta o grafo de dependências, detecta ciclos e define a ordem de execução (ordenação topológica)
  • 6 camadas (raw, staging, qualidade, core, mart e publicação), com modelo dimensional e segmentação RFM de clientes
  • Checks de qualidade com quarentena de registros inválidos e reconciliação de receita: se algo falha, nenhum número inválido é publicado
  • Execuções idempotentes e transacionais, com testes automatizados e visualização interativa do DAG
  • Python
  • SQL
  • SQLite
  • Data quality
  • unittest
